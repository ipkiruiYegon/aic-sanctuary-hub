# aic-sanctuary-hub
AIC Sanctuary Hub is a modern web application built with FastAPI and Jinja templates to serve as a centralized digital platform for AIC church officials. It provides a simple, secure, and engaging way to stay updated on church activities, receive timely notifications, and strengthen fellowship through technology.

---
## ✨ Purpose
- Create a digital sanctuary where church officials can gather virtually.

- Simplify event management and communication within the church community.

- Encourage participation and connection by delivering updates directly to church officials.

---

---

## ✨ Features
- 📅 **Event Scheduling & Management** – Create, update, and view upcoming church events.
- 🔔 **Notifications** – Send and receive alerts for important updates.
- 👥 **Officials Engagement** – Encourage participation and communication.
- 🎨 **Responsive UI** – Built with Jinja templates for a clean, modern interface.
- 🔒 **Secure Access** – Authentication and role-based permissions.

---

## 🛠 Tech Stack
- **Backend:** FastAPI  
- **Frontend:** Jinja2 Templates, HTML, CSS, JavaScript, HTMX, Tailwind CSS and DaisyUI  
- **Database:** PostgreSQL 
- **Deployment:** Uvicorn   
- **Version Control:** Git & GitHub
